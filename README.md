# weiye-lucy-sOscilloscope
## 项目说明
本项目为本人与卢昕郁（lucy）（现北京交通大学通信工程专业）合作完成的嵌入式学习项目。
### 合作者分工

| 成员 | 主要负责内容 |

| 韦烨宸（本人） | 系统整体框架搭建；TIM3 TRGO硬件触发ADC + DMA循环搬运链路配置；动态采样率配置（256Hz~768kHz）；时域波形显示（起始点对齐、防抖动）；5按键+编码器交互；OLED三模式显示逻辑 |

| 卢昕郁 | FFT算法实现与移植；自动频率跟踪（Right_Fre迭代收敛）；频谱分析与波形类型识别的理论支持 |

### 关于FFT与自动频率跟踪的说明

本项目中的FFT为**移植的浮点FFT实现**，自动频率跟踪（Right_Fre）的迭代收敛逻辑，均由合作者卢昕郁提供并主导调试。本人负责FFT的调用、数据格式转换、归一化处理、峰值检测等应用层代码，以及自动频率跟踪的调用与基本理解。这两部分的核心算法不属于本人原创。

## 个人贡献说明

### 本人（韦烨宸）负责部分

- 系统整体架构设计与外设资源分配
- ADC+DMA+TIM3采样链路的配置与调试
- 动态采样率配置算法（Set_SamplingFre）
- 时域波形起始点对齐与防抖动处理

- FFT算法的实现与移植
- 自动频率跟踪（Right_Fre迭代收敛）
- 频谱分析与波形类型识别的理论支持
- 部分代码调试协助

### 第三方依赖
