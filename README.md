# weiye-lucy-sOscilloscope
## 项目说明
本项目为本人与卢昕郁（lucy）（现北京交通大学通信工程专业）在2025年2~5月合作完成的嵌入式学习项目，灵感来源于宿舍开发环境简陋，无法使用示波器测试和查找嵌入式学习实操过程中出现的错误。
### 合作者分工

| 成员 | 主要负责内容 |

| 韦烨宸（本人） | 系统整体框架搭建；TIM3 TRGO硬件触发ADC + DMA循环搬运链路配置；动态采样率配置（256Hz~768kHz）；时域波形显示（起始点对齐、防抖动）；5按键+编码器交互；OLED三模式显示逻辑 |

| 卢昕郁 | FFT算法实现与移植；自动频率跟踪（Right_Fre迭代收敛）；频谱分析与波形类型识别的理论支持 |

### 关于FFT与自动频率跟踪的说明

本项目中的FFT为**移植的浮点FFT实现**，自动频率跟踪（Right_Fre）的迭代收敛逻辑，均由合作者卢昕郁提供并主导调试。本人负责FFT的调用、数据格式转换、归一化处理、峰值检测等应用层代码，以及自动频率跟踪的调用与基本理解。这两部分的核心算法不属于本人原创。

### 接线：
PA0 → KEY0按键（另一端接GND，切换显示模式）

PA1 → 信号输入（0~3.3V，外部信号源，地要与单片机共地）

PA2 → KEY2按键（另一端接GND，暂停/恢复采集）

PA3 → KEY3按键（另一端接GND，切换频谱显示）

PA4 → KEY4按键（另一端接GND，重新自动跟踪频率）

PA5 → KEY5按键（另一端接GND，切换编码器控制对象）

PA8 → 编码器A相（TIM1_CH1）

PA9 → 编码器B相（TIM1_CH2）

PB0 → OLED SDA（I2C数据）

PB1 → OLED SCL（I2C时钟）

PB10 → 调试串口TX（USART3_TX，接USB转TTL的RX）

PB11 → 调试串口RX（USART3_RX，接USB转TTL的TX）

PC13 → 板载LED（低电平点亮，按键时翻转）

3.3V → OLED VCC、编码器VCC、按键上拉（若外部无上拉）

GND → OLED GND、编码器GND、按键公共端、信号源地

注意：OLED的SDA接PB0、SCL接PB1，不要接反。按键和编码器均为上拉输入，另一端接GND
